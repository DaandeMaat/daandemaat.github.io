    Project 1: Royal Flora Holland

    Als deel van studie heb ik een webapplicatie ontwikkeld voor Royal Flora Holland. Deze webapplicatiie had als doel om Royal Flora Holland de mogelijkheid te geven om online veilingen te hosten. Dit was mijn eerste echte ervaring met web development en ik heb deze opdracht met vier groepsgenoten uitgevoerd. De opdracht was taai helemaal aangezien ik in deze opdracht voor het eerst met dingen zoals HTML, CSS en JavaScript werkte. Echter heeft deze opdracht wel mijn intresse in Software engineering evenals web development gestimuleerd hier ga ik in mijn tweede projecten beschrijving verder op in.

    Project 2: Hulstman en de Maat
